Scomm.AI for Outlook

OpenPGP encrypt, sign, decrypt, and verify in Outlook, with keys from pubkey.scomm.ai.

Microsoft disabled Add from URL for custom Outlook add-ins. Download the manifest, then use Add from File.

Download scomm-ai-outlook.xml

If the browser shows XML instead of saving, use File → Save As and keep the .xml extension.

Install

  1. Open the add-in dialog: https://aka.ms/olksideload (or classic Outlook: File → Manage Add-ins).
  2. My add-ins → bottom Custom add-ins.
  3. Add a custom add-in → Add from File → choose the downloaded XML → Install.
  4. Restart Outlook. On a mail item, the ribbon group is Scomm.AI.

Microsoft 365 / Exchange Online mailbox required. Classic Outlook may take a while to show a newly sideloaded add-in (client cache).

Admins: deploy the same XML in Microsoft 365 admin center → Integrated apps. Manifest: https://office.scomm.ai/manifest.xml
