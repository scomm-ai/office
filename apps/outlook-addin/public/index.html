Scomm.AI for Outlook

OpenPGP encrypt, sign, decrypt, and verify in Outlook, with keys from pubkey.scomm.ai.

Manifest URL (Add from URL)
https://office.scomm.ai/manifest.xml

Download manifest.xml · Open task pane

Install

  1. Outlook: Get Add-ins → My add-ins.
  2. Add a custom add-in → Add from URL.
  3. Paste https://office.scomm.ai/manifest.xml → OK.

Classic Outlook (Windows): Home → Get Add-ins, or File → Manage Add-ins. Microsoft 365 / Exchange Online mailbox required.
